HOW TO USE

드릴 → 노트 → 실제 클러스터

  1. 드릴에서 한 과제씩 즉시 채점받으며 명령 형태를 손에 붙입니다.
  2. 틀린 과제의 개념은 노트에서 판별 기준으로 정리합니다.
  3. 같은 과제를 실제 클러스터에 적용해 확인합니다. 이 페이지는 클러스터를 대신하지 못합니다.
  4. 마지막 주에는 모의 세션으로 시간 압박과 배점 배분을 익힙니다.
