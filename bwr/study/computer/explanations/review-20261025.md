# 해설 검토 근거 — 2026-10-25

요청 6문항과 동일 판단 기준의 유관 24문항에 해설을 추가했다. 기존 상세 해설 309개는 수정하지 않았다.

- Windows 문항은 지문에 적힌 Windows 7·10 또는 XP 기준을 명시했다. 최신 버전의 메뉴와 동일하다고 가정하지 않았다. [Microsoft 작업 표시줄 안내](https://support.microsoft.com/en-us/windows/experience/personalization/customize-the-taskbar-in-windows)
- 비밀번호 주기적 변경을 권장한 옛 기출은 원래 정답을 유지하되 현대 권고와 구분했다. NIST는 임의의 정기 변경을 요구하지 않으며 유출 증거가 있을 때 변경하도록 한다. [NIST SP 800-63B](https://pages.nist.gov/800-63-4/sp800-63b.html)
- DMB는 디지털 멀티미디어 방송이다. 2017.09.02 1번은 커뮤니케이션과 방송을 구분한 출제 분류이며, DMB가 모바일 멀티미디어가 아니라는 뜻으로 해설하지 않았다. [방송통신위원회 DMB 활용 및 대체방안 연구](https://www.kmcc.go.kr/download.do?fileSeq=61315)
- 디지털·아날로그는 데이터 표현과 처리 방식의 구분이다. 디지털 컴퓨터가 그래프를 출력하지 못한다거나 처리 속도의 우열이 항상 정해져 있다는 해석을 피했다.

검증: 전체 1,792문항의 ID·보기·정답 구조, 83개 개념 ID, 339개 해설 참조와 300자 제한, 기존 해설 보존, 새 30개 해설의 실제 로더 등록과 개념 매칭을 확인했다.
